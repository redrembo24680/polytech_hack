# Голосовий канал (Vapi): налаштування

## Що налаштовано
- Асистент Vapi `<VAPI_ASSISTANT_ID>` (з `.env`), створюється/оновлюється `scripts/vapi_setup.py`.
- Транскрайбер: Deepgram `nova-3`, мова `uk` (підтримується Deepgram; ключ провайдера не потрібен).
- Голос: Azure `uk-UA-PolinaNeural`. Модель: OpenAI `gpt-4o` (Vapi-hosted), короткий український системний промпт.
- Tools: усі інструменти агента як server tools; `server.url` = `PUBLIC_URL/voice/tools`; `serverMessages` = `tool-calls`.
- Номер: безкоштовний US-номер Vapi (`VAPI_PHONE_NUMBER` у `.env`).
- Клієнта визначає сервер за номером дзвінка (`call.customer.number`); `get_client_profile` без аргументів.

## Запуск
1. `uv run uvicorn agent.main:app --port 8000`
2. `ngrok http 8000`, скопіювати https-URL у `PUBLIC_URL` в `.env`.
3. `uv run python scripts/vapi_setup.py` (PATCH наявного асистента; `--number` підключає номер).
4. Перевірка вебхука:
   `curl -s -X POST "$PUBLIC_URL/voice/tools" -H 'content-type: application/json' -d '{"message":{"type":"tool-calls","toolCallList":[{"id":"t1","function":{"name":"get_client_profile","arguments":{}}}],"call":{"customer":{"number":"+380501110001"}}}}'`
   Очікується 200 і профіль клієнта. Номер має бути в даних джерела (власний seed: `+380501110001`; дані сайту: `+380671234501`).

## Тестування
- Без витрат на дзвінок: кнопка "Talk to assistant" у дашборді Vapi (веб-дзвінок з браузера; номер дзвінка невідомий, тож клієнта не буде знайдено, якщо не задати customer number) або curl вище.
- Реальний дзвінок: набрати `VAPI_PHONE_NUMBER` з телефону (міжнародний виклик до США, платний за тарифом оператора).
- Вихідні дзвінки з Vapi не запускаємо: коштують кредити й дзвонять на реальний телефон.

## Обмеження
- Безкоштовний номер Vapi працює лише з US-дзвінками, один-два номери на акаунт.
- Українське STT/TTS: можливі помилки розпізнавання імен і дат; голос говорить повільніше за англійський.
- ngrok free: URL змінюється при перезапуску, тоді треба повторити крок 3.

## Апруви в голосі
Дії, що потребують схвалення (refund, винятки), повертають `pending_approval`. Асистент говорить, що перевірить з адміністратором і зв'яжеться з клієнтом; рішення приймає адміністратор у панелі. Картки (`show_card`) надсилаються клієнту SMS-повідомленням.
