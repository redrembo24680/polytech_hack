# Демо-відео (фінальні записи)

Записано Playwright-скриптом `support-agent/scripts/demo/run_demo.py` 31.10.2026 ~16:10 (headless, ~6 хв на всі сцени;
Claude Sonnet виконавець і оркестратор, Gemma 4 12B відповідач, дані платформи `site/`).
Кожна сцена у двох ракурсах: `*-customer.mp4` — чат клієнта на сайті, `*-admin.mp4` — адмінка сайту (`/admin/{tenant}`).
Записи містять крок SMS-підтвердження номера (демо-код 1234) і погодження дій агента прямо в адмінці сайту
(панель «Погодження дій агента»). Загалом ~3 МБ (CRF 26).

| Файл | Сцена |
|---|---|
| Q-* | Просте питання (ціна, адреса) — відповідає Gemma 4 без дій |
| A-* | Олена: пізнє перенесення, виняток автоматично, вибір слота |
| B-* | Максим: виняток потребує апруву → адміністратор схвалює в адмінці → перенесено зі збереженою передоплатою |
| C-* | Петро (DentaPlus): повернення + скасування через два апруви в адмінці |

Перезапис: `cd support-agent && uv run python scripts/demo/run_demo.py --scene ALL --headless --admin site --mp4`
(старий варіант з copilot: `--admin copilot`).
