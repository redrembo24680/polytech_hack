# Запис демо-відео

Playwright проходить сценарії в справжньому браузері (з видимим курсором і набором тексту) і зберігає `videos/<сценарій>.mp4` для презентації.

## Підготовка (один раз)
```bash
cd site/demo-video
uv sync
uv run playwright install chromium
```
Стек має бути запущений: `cd site && docker compose up -d`. Перед кожним сценарієм дані скидаються (`POST /api/admin/reset`), після запису теж.

## Сценарії
| Сценарій | Що на відео |
|---|---|
| `agent` | Клієнт (Олена) пише в чат підтримки на `/b/lumen/support` → агент відповідає й діє → адмінка, картка `b-olena-1` з історією (дії агента з міткою «AI») → інбокс підтримки |
| `tour` | Головна → сторінка Lumen Beauty → онлайн-запис → адмінка (тиждень, клієнти, майстри, послуги, налаштування AI) |
| `widget` | «Власний сайт салону» `/demo-salon-site.html` з віджетом чату → питання в чат |

```bash
uv run python record.py --scenario agent      # або tour / widget / all
```

Для сценаріїв `agent` і `widget` агент має бути підключений: у `site/.env` задано `AGENT_URL`, і бекенд перезапущено (`docker compose up -d backend`). Якщо агента немає, у чаті буде заглушка, а скрипт надрукує попередження.

## Корисні параметри
- `--message "..."` — повідомлення клієнта; повторіть кілька разів для кількох реплік (після кожної скрипт чекає відповіді агента).
- `--client-name`, `--client-phone`, `--booking-id` — інший клієнт (напр. Максим: `--client-name Максим --client-phone "+380 67 123 45 02" --booking-id b-max-1`; телефони дивіться в адмінці).
- `--tenant dentaplus` — клініка замість салону.
- `--agent-timeout 180` — скільки чекати відповіді агента (с).
- `--read-time 6` — пауза після кожної відповіді, щоб глядач встиг прочитати.
- `--pace 1.5` — повільніше (або `0.7` швидше).
- `--headed` — бачити браузер під час запису.

Довге очікування відповіді агента можна вирізати в монтажі, або пришвидшити відео.

ffmpeg береться з пакета `imageio-ffmpeg` (Homebrew-збірка на цьому Mac зламана).
