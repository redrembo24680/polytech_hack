# admin-panel

Адмін-панель власника бізнесу: `/admin/[tenant]/…`. Бічне меню з назвою бізнесу, бейджем відкритих тікетів і кнопкою «Скинути демо».

Сторінки:
- Бронювання (`/admin/[tenant]`) — тижнева сітка, картка бронювання з історією (Timeline) і діями, створення бронювання (Task 16).
- Клієнти, Майстри, Послуги — CRUD (Task 17).
- Налаштування (`/settings`) — дані бізнесу та повна політика, включно з дозволами AI-агента (Task 18).
- Підтримка (`/support`) — вкладки «Розмови» (відповідь як адміністратор), «Тікети», «Повідомлення» (Task 18).

Усі дії адміністратора йдуть з `by: "human:admin"`; зміни AI-агента позначаються бейджем «AI». Дані оновлюються опитуванням (3–5 с).
