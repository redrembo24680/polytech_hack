# Підводні камені

- `refund_auto_limit` має сенс лише при `refund = auto_under_limit`; в іншому випадку поле вимкнене, але значення зберігається й відправляється.
- Політика зберігається повним об'єктом (PUT); форма ініціалізується з серверної політики один раз — зміни іншим вкладкам видно після перезавантаження.
- Відповідь у закритій розмові дає 409 — спершу «Відкрити знову».
- Назва клієнта в тікетах і журналі береться зі списку клієнтів; якщо клієнта немає в списку, показується id.
- `PageProps<"/admin/[tenant]/…">` потребує згенерованих типів маршрутів (`next typegen` або запуск dev-сервера) перед `tsc`.
- Серверні компоненти імпортують `@/lib/api-core`, клієнтські — `@/lib/api`.
- Опитування (3 с) не зупиняється у фоновій вкладці.
