# Наскрізний сценарій

1. Власник відкриває `/admin/lumen/settings`, ставить «Вікно скасування» 12 год -> `PUT /api/tenants/lumen/policy` (повний об'єкт Policy) -> `/b/lumen` одразу показує «12 год».
2. Клієнт пише в чат; AI-агент відповідає; якщо потрібне рішення людини — `POST /tickets`. Тікет з'являється у вкладці «Тікети» і в бейджі меню протягом 3–5 с.
3. Власник відкриває розмову у вкладці «Розмови», пише відповідь -> `POST …/support/conversations/{id}/reply {text, role: "human"}`; у клієнтському чаті повідомлення з підписом «Адміністратор».
4. Власник закриває тікет (`PATCH /tickets/{id} {status: "closed"}`) або розмову (`PATCH …/conversations/{id} {status}`).
5. Вкладка «Повідомлення» показує журнал вихідних (`GET /messages`): чат/SMS клієнтам, надіслані агентом.
6. Зміна назви бізнесу (`PATCH /api/tenants/{t}`) оновлює меню завдяки `router.refresh()`.
