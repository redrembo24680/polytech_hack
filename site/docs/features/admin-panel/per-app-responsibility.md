# Відповідальність застосунків

- **web** (`app/web`): увесь UI адмінки; клієнтські компоненти опитують API через SWR (`useApi` з `refreshMs`), мутації через `api.post/patch/put/del`.
- **backend**: джерело даних і правил цілісності (ендпоінти `booking-api` та `support-chat`); не перевіряє `agent_permissions`.
- **mcp / AI-агент**: читає політику й сам застосовує `agent_permissions`; результати його дій (події `by: "agent"`, тікети, повідомлення) адмінка лише відображає.
