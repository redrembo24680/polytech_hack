# Бізнес-контекст

Власник салону чи клініки хоче бачити, що робить AI-агент, і керувати його свободою. Адмінка показує бронювання, змінені агентом (бейдж «AI», хронологія подій), а в налаштуваннях власник сам визначає, що агент робить без питань («Сам»), що потребує погодження, а що заборонено.

Коли агент не може вирішити питання, він створює тікет і/або пише клієнту; власник бачить це в «Підтримці» наживо та може вручну відповісти клієнту в чаті від імені «Адміністратора».
