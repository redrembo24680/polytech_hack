# Бізнес-контекст

Бізнес уже має власний сайт і не хоче переносити його на платформу. Достатньо вставити один рядок, щоб відвідувачі отримали AI-підтримку (запис, перенесення, скасування, питання). Розмови потрапляють в адмінку `/admin/<tenant>/support`. У демо доводить, що підтримка перевикористовується на будь-якому сайті.
