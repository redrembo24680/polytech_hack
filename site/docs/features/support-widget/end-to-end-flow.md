# Наскрізний потік

1. Сторінка бізнесу завантажує `<script src=".../widget.js" data-tenant="lumen">`.
2. Скрипт визначає origin зі свого `src`, додає кнопку (правий нижній кут).
3. Клік: лениво створюється iframe `${origin}/b/lumen/support?embed=1`, панель 380x600 (на екранах <480px — на весь екран).
4. Клієнт вводить ім'я й телефон, пише повідомлення; AI-агент відповідає (див. `support-chat`).
5. Розмова видима в `/admin/lumen/support`. Кнопка закриття або повторний клік ховає панель (iframe зберігається).
