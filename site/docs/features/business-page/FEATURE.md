# business-page

Публічна сторінка бізнесу `/b/[tenant]` і сценарій онлайн-запису `/b/[tenant]/book` у Next.js-застосунку (`app/web`).

Дає:
- Профіль бізнесу: назва, тип (Салон/Клініка), опис, адреса, телефон, Instagram (якщо є).
- Майстрів із послугами, які вони виконують; послуги з тривалістю («60 хв») і ціною («700 грн»).
- Правила скасування людською мовою — `policyToText(policy)` (без `agent_permissions`).
- Кнопки «Записатись» (`/b/[tenant]/book`) і «Підтримка» (`/b/[tenant]/support`).
- Запис: послуга -> майстер або «Будь-хто» -> день (7 днів від сьогодні, Europe/Kyiv) -> час -> ім'я і телефон -> підтвердження.
- Помилки: 409 `slot_taken` -> «Цей час щойно зайняли» і оновлений список слотів; інші `ApiError` показують своє `message`.
