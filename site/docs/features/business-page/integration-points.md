# Точки інтеграції

- REST API бекенда (`NEXT_PUBLIC_API_URL` у браузері, `INTERNAL_API_URL` на сервері Next): tenants, services, staff, slots, bookings.
- Посилання на `/b/[tenant]/support` (чат підтримки, окрема фіча support-widget).
- Посилання на Instagram бізнесу (`https://instagram.com/<handle>`) і `tel:` для телефону.
- Бронювання, створені тут, одразу видно в адмінці й агенту (через MCP).
