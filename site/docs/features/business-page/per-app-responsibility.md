# Відповідальність застосунків

- **web (`app/web`)** — уся фіча: сторінки, форма запису, `policyToText`, форматування цін/часу, обчислення меж дня в Києві.
- **backend** — дані тенанта, послуг, майстрів; розрахунок вільних слотів; створення клієнта за телефоном (нормалізація) і бронювання; розрахунок передоплати; відповідь 409 `slot_taken`.
- **mcp** — не бере участі.
- **agent** — не бере участі напряму; бачить створені сторінкою бронювання через MCP як звичайні (`by: "human:client"`).
