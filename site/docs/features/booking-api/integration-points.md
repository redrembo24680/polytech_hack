# Точки інтеграції

- **Postgres**: `DATABASE_URL` (на хості порт 5433); тести — база `booking_test`.
- **MCP-сервер** і **зовнішній AI-агент** викликають ці ендпоінти по HTTP; форма запитів/відповідей — контракт агента, не змінювати.
- **Фронтенд**: `NEXT_PUBLIC_API_URL` (CORS з `cors_origins`).
- **Адмінка** шле `by: "human:admin"`; агент — `by: "agent"`.
- `POST /api/admin/reset` — скидання демо-даних між прогонами.
