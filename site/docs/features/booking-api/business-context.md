# Бізнес-контекст

Платформа обслуговує бізнеси, що працюють за записом (салон «Lumen», клініка «DentaPlus»). Кожен бізнес (тенант) має власну
політику: вікно скасування, штраф за no-show, передоплата, штраф за пізню зміну та `agent_permissions`.

AI-агент підтримки (окремий проєкт) виконує реальні дії: переносить і скасовує записи, повертає передоплату, знімає штраф,
робить виняток-«goodwill», шле повідомлення, заводить тікети. Рішення «чи можна» приймає агент за політикою тенанта;
цей API лише виконує дію й дбає про цілісність (немає накладок, коректні переходи станів, суми в межах передоплати).

Гроші — цілі гривні. Час — ISO 8601 з офсетом, таймзона тенантів `Europe/Kyiv`.
