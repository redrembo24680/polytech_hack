# Відомі підводні камені

- `to` у `/slots` обмежує **початок** слота, а не його кінець.
- Datetime мають містити офсет (`...+02:00`, `Z`); без офсету -> 422 `validation`. Будь-який офсет коректно порівнюється з київським часом. Дата `YYYY-MM-DD` = північ у таймзоні тенанта.
- Телефони нормалізуються до цифр (`+380 67 123-45-67` і `0671234567` -> `380671234567`); дубль у тенанті -> 409 `invalid_state`.
- Апка не перевіряє `agent_permissions` та політику (вікно скасування, ліміти повернення) — це робота агента; апка перевіряє лише цілісність.
- `reset` перегенеровує сід відносно поточного часу, тож «завтра» в демо зсувається разом із днем запуску.
- Немає блокувань: одночасне бронювання того самого слота двома запитами може пройти обидва (перевірка `is_slot_free` і запис не атомарні).
- Cancelled-бронювання не блокують слот; refund не залежить від статусу бронювання (лише від `prepayment.status == held`).
- Reschedule із `staff_id`, що не надає послугу, -> 422, а не 409.
