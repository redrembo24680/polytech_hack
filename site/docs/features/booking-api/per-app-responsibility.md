# Відповідальність по застосунках

- **backend (`app/backend`)** — уся логіка цієї фічі: API, цілісність даних, сід, скидання.
- **mcp (`app/mcp`)** — обгортає ці ендпоінти як інструменти для агента (`APP_API_URL`). Не стосується цієї фічі напряму, лише споживач.
- **web (`app/web`)** — адмінка й публічні сторінки ходять у цей API (`NEXT_PUBLIC_API_URL`).
- **AI-агент (зовнішній)** — вирішує, чи дозволена дія (`agent_permissions`), і викликає API.
