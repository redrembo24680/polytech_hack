# Бізнес-контекст

Клієнт салону чи клініки пише в чат, і AI-агент підтримки вирішує його проблему (перенос, скасування, повернення передоплати,
виняток тощо), користуючись API бронювань. Телефон потрібен, щоб агент знайшов клієнта й його бронювання (`client_id`
розмови визначається за нормалізованим телефоном). Якщо агент не впорався, відповісти може людина-адміністратор
(роль `human`, підпис «Адміністратор») через адмінку.
