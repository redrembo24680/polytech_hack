# Відповідальність по застосунках

- **web** — сторінка чату, збереження id розмови, опитування; нічого не знає про агента.
- **backend** — зберігає розмови/повідомлення, викликає вебхук агента `POST {AGENT_URL}/chat`, віддає заглушки.
- **AI-агент (зовнішній)** — реалізує `POST /chat`, викликає API бронювань (прямо або через MCP) і за потреби пише через `/reply`.
- **mcp** — інструменти агента; до чату напряму не належить.
