# support-chat

Чат підтримки для клієнта: сторінка `/b/[tenant]/support` (і режим `?embed=1` для iframe-віджета), бекенд-ендпоінти
розмов і вебхук до зовнішнього AI-агента підтримки.

Дає:
- Форму старту («Ім'я», «Телефон») -> розмова; продовження після перезавантаження (`localStorage` `support:<tenant>`).
- Стрічку з ролями `client` / `agent` («AI-асистент») / `human` («Адміністратор»), індикатор «Агент друкує…», опитування кожні 2 с.
- Контракт `POST {AGENT_URL}/chat` для агента (див. `integration-points.md`) і тестового агента-ехо `app/backend/scripts/echo_agent.py`.
- Заглушки, коли агента немає або він недоступний.
