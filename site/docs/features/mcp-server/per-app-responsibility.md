# Відповідальність по застосунках

- `app/mcp` — перетворює виклики інструментів на HTTP-запити до API, нормалізує відповіді (успіх -> JSON, помилка -> текст), описує інструменти для LLM. Бізнес-логіки й перевірки політики не містить.
- `app/backend` — уся бізнес-логіка та цілісність даних (див. `booking-api`).
- Агент підтримки (поза цим репо) — приймає рішення за політикою й викликає інструменти.
- `app/web` — не взаємодіє з MCP.
