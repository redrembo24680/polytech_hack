# Бізнес-контекст

AI-агент підтримки (окремий проєкт тіммейта) спілкується з клієнтами салону «Lumen» і клініки «DentaPlus» і має виконувати реальні дії: переносити та скасовувати записи, повертати передоплату, знімати штраф за no-show, фіксувати goodwill-винятки, писати клієнту й заводити тікети для людини.

MCP-сервер дає агенту ці дії як інструменти за стандартним протоколом, тож агент не прив'язаний до деталей HTTP API.

Рішення «чи можна» (вікно скасування, ліміти повернення, `agent_permissions`) приймає агент за політикою тенанта (`get_tenant`). MCP-сервер та API лише виконують дію й стежать за цілісністю даних. Помилки (зайнятий слот, неприпустимий стан) повертаються текстом, щоб агент міг пояснити клієнту й спробувати інший варіант.
